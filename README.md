## Проекты

### [StudentHub](https://github.com/T1xnik/Journal-Universel-Versual)

Неофициальный десктопный клиент электронного журнала на PySide6: расписание,
домашние задания, оценки, рейтинг группы и профиль в одном окне.
Тёмная и светлая темы, RU/EN, локальный кэш, аккуратная работа с rate-limit.

`Python` · `PySide6` · `httpx` · `pydantic`

### [ARCH-Config-Lua](https://github.com/T1xnik/ARCH-Config-Lua)

Рабочий конфиг Hyprland для Arch Linux и CachyOS: прозрачность, обои и
визуальные улучшения. Проверено на Hyprland 0.39+.

`Lua` · `Hyprland` · `Arch Linux`
